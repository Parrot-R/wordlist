# category: tokens / unicode-confusables
# purpose: Unicode confusable (lookalike) character substitutions used to smuggle
#          attack keywords past ASCII-level filters. The attacker replaces one or more
#          ASCII characters with a visually identical codepoint from Cyrillic, Greek,
#          Armenian, or fullwidth Latin — the string renders the same to a human but
#          bytes are different, so keyword matchers see gibberish.
# format (Part A): U+NNNN SCRIPT NAME → replaces → U+0041 ASCII NAME (one pair per line)
# format (Part B): confusable-substituted attack keywords — actual test strings
# source-level: Unicode Consortium UTS-39 Confusables (confusables.txt, public),
#               Cyrillic/Greek homoglyph catalogs used in IDN homograph attacks,
#               subset that overlaps common LLM-filter trigger words.
# defense: UTS-39 confusable-fold (map each char to its ASCII skeleton), then re-run
#          the filter. See examples/string_transforms.py::confusable_fold().
# NOTE: Part B strings are stored as literal Unicode so they serve as usable test inputs.
#       The invisible-char hygiene rule (F-006) does not apply — these are visible chars.
